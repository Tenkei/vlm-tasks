# Security policy

This policy covers `ml-pipes-vlm` and follows the shared
[ml-pipes security policy](https://github.com/trained-by-humans/ml-pipes/blob/main/SECURITY.md).

Report vulnerabilities affecting the latest release or current `main` branch
through this repository's GitHub Private Vulnerability Reporting. Include the
package version or commit, a minimal reproduction and dependency versions.
Keep sensitive reports private.

Package code, model integration boundaries, packaging and release workflows
are in scope. Report dependency vulnerabilities to their maintainers.
Application credentials, infrastructure and downstream deployment configuration
are owned by the application.
